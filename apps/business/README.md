# 💼 Business — بوابة التجار

موقع لايت بوتيك للتجار والمنتجين لشراء ومبيع تجار في منصة **Ray**.

---

## 1. المعمارية

| القطعة       | التقنية                           | المسار           |
| ------------ | --------------------------------- | ---------------- |
| بوابة التجار | Next.js + TypeScript + Tailwind 4 | `apps/business/` |

---

## 2. المهارات

- **لوحة التحكم**: إدارة المتاجر، الرعاية، التوصيل، الإشعارات، الإعدادات
- **المتاجر**: إدارة المتاجر، المنتجات، المبيعات، العملاء
- **التوصيل**: إدارة الكوادر، المسارات، التكاليف

---

## 3. الإعداد والتشغيل

```bash
cd apps/business
npm install
npm run dev   # http://localhost:3000
```

### متغيرات البيئة

| المتغير                    | الافتراضي               | الوصف              |
| -------------------------- | ----------------------- | ------------------ |
| `BACKEND_URL`              | `http://localhost:4000` | عنوان الباك إند    |
| `NEXT_PUBLIC_BUSINESS_URL` | `http://localhost:1000` | رابط بوابة الأعمال |

---

## 4. الإخلاص والأمان

- `sanitizeHtml()` على `innerHTML`
- `HttpOnly` cookies + `X-CSRF-Token`
- CSP، HSTS، X-Frame-Options
- `Authorization: Bearer` في `localStorage` (مع `clearToken()` عند الخروج)
