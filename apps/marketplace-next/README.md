# 🛒 marketplace-next — المتجر العام

المتجر العام للعملاء — **سوق، حجز، دفع، وتوصيل**.

---

## 1. المعمارية

| القطعة       | التقنية                                        | المسار                   |
| ------------ | ---------------------------------------------- | ------------------------ |
| المتجر العام | Next.js (App Router) + TypeScript + Tailwind 4 | `apps/marketplace-next/` |

---

## 2. المهارات

- **التسوق**: بحث، تصفح، تصفية، ترتيب
- **الحجز**: reserving المنتجات والخدمات
- **الدفع**: تكامل مع البوابات المصرية والدولية
- **التوصيل**: إدارة الطلبات، المسارات، التكاليف
- **العروض**: إنشاء وإدارة العروض والخصومات

---

## 3. الإعداد والتشغيل

```bash
cd apps/marketplace-next
npm install
npm run dev   # http://localhost:3000
```

### متغيرات البيئة

| المتغير                    | الافتراضي               | الوصف              |
| -------------------------- | ----------------------- | ------------------ |
| `BACKEND_URL`              | `http://localhost:4000` | عنوان الباك إند    |
| `NEXT_PUBLIC_BUSINESS_URL` | `http://localhost:1000` | رابط بوابة الأعمال |

---

## 4. الإخلاص والأمان

- `HttpOnly` cookies + `X-CSRF-Token`
- CSP، HSTS، X-Frame-Options
- `Authorization: Bearer` في `localStorage` (مع `clearToken()` عند الخروج)
